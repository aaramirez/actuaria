# Ciencia de datos actuariales

La matemática y los datos detrás de un seguro: mortalidad y seguros de vida, tarificación no vida con frecuencia, severidad, GLM y credibilidad, reservas con triángulos, reaseguro, solvencia y el uso de la ciencia de datos en una aseguradora.

**Ver en línea:** https://aaramirez.github.io/actuaria/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
